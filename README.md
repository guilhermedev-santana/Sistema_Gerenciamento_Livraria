Sistema de Gerenciamento de Livraria

Sistema para gerenciamento de uma livraria, com persistência de dados em MySQL.

Sobre o projeto

Modela o controle de um acervo de livraria — cadastro de livros, autores, clientes e/ou vendas — com os dados armazenados em um banco de dados relacional.
Projeto desenvolvido durante o curso de Análise e Desenvolvimento de Sistemas (SENAI), com foco em fixar conceitos de banco de dados relacional (modelagem, SQL e integração com a aplicação).
